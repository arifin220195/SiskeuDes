================================================================
SISKEUDES - DAFTAR & PENJELASAN FILE SQL
================================================================
Semua file ada di folder: supabase/migrations/

Cara pakai:
1. Buka file SQL di text editor
2. Ctrl+A (pilih semua) -> Ctrl+C (salin)
3. Supabase -> SQL Editor -> + New query (tab baru)
4. Ctrl+A -> Ctrl+V (hapus + tempel)
5. Klik Run
6. Setelah sukses, RENAME tab biar rapi:
   klik judul "Untitled" di atas -> ketik nama di DAFTAR SAMPAI BAWAH INI -> Enter
